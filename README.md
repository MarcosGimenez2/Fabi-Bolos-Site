# 🎂 Fabi Bolos

Site desenvolvido para divulgação de bolos artesanais e personalizados, com foco em apresentar os trabalhos realizados e facilitar o contato para encomendas.

🔗 **Acesse o projeto:**
https://fabi-bolos-site.vercel.app/
## 💻 Sobre o projeto

O Fabi Bolos foi desenvolvido como um projeto prático utilizando Angular.

O objetivo foi criar uma interface moderna, responsiva e de fácil navegação, permitindo que os clientes conheçam alguns dos trabalhos realizados, consultem informações de pagamento e entrem em contato diretamente pelas redes sociais.

## 🚀 Tecnologias utilizadas

- Angular
- TypeScript
- HTML
- CSS
- Font Awesome
- Git
- GitHub
- Vercel

## ✨ Funcionalidades

- Layout responsivo para desktop e dispositivos móveis
- Galeria de bolos
- Navegação entre páginas
- Página com formas de pagamento
- Página de contato
- Integração direta com WhatsApp
- Integração com Instagram
- Deploy automático pela Vercel

## 📱 Responsividade

O projeto foi desenvolvido pensando também na experiência em dispositivos móveis, adaptando elementos da interface para diferentes tamanhos de tela.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, coloquei em prática conceitos de desenvolvimento front-end com Angular, estilização responsiva, componentização, controle de versão com Git/GitHub e publicação de aplicações web.

O projeto também me permitiu trabalhar na identificação e correção de problemas de interface entre desktop e mobile.
